# GeometryLib

Python-библиотека для вычисления площади круга и треугольника, с возможностью проверки прямоугольного треугольника.

## Возможности
- Расчет площади круга
- Расчет площади треугольника по 3 сторонам
- Проверка на прямоугольный треугольник
- Расширяемость: легко добавить другие фигуры
- Поддержка полиморфизма

## Установка

```bash
pip install -r requirements.txt
```

## Тесты

```bash
python -m unittest test_geometry.py
```
